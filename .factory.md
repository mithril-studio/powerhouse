# Powerhouse — notes for factory runs

Powerhouse is a Tauri desktop app for macOS: React and Vite in `src/`, Rust in `src-tauri/`.
`AGENTS.md` describes the project; read it. Where it and this file disagree about how work
lands, this file wins for a factory run:

- Do not run `scripts/land.sh`, and do not push to `test` or `main`. Push your own branch and
  open the pull request into `test` that the run's instructions ask for. `AGENTS.md` tells its
  worktree agents to land on `test` themselves and never open a pull request; a factory run is
  the exception, because its pull request is how the work gets reviewed.
- Do not bump the version, push tags, or run `scripts/ship.sh`, `scripts/release.sh`,
  `scripts/beta.sh` or `scripts/bump.sh`. Releases are the human's.
- Write commit subjects the way `AGENTS.md` asks: one line, imperative, says what changed. They
  are listed in the app's Merge tab.

## Setup

`pnpm install --frozen-lockfile`, under 10 seconds. Run it once, before anything else.

Use pnpm, not npm. CI installs with pnpm and `pnpm-lock.yaml` is the lock file that counts;
ignore `package-lock.json`. Change neither unless the issue adds or removes a dependency.

## Verify

- `pnpm build` (typecheck and Vite bundle) and `pnpm test` (vitest), each about 10 seconds.
  They are what CI runs on the pull request.
- `./scripts/land.test.sh` if you changed `scripts/land.sh`.
- If you changed anything in `src-tauri/`, install Rust and Tauri's Linux libraries once (about
  70 seconds), then run the Rust tests (about 3 minutes the first time, mostly compiling):

  ```bash
  timeout 600 bash -c 'sudo apt-get update -qq && sudo DEBIAN_FRONTEND=noninteractive apt-get install -y -qq build-essential libwebkit2gtk-4.1-dev libssl-dev libayatana-appindicator3-dev librsvg2-dev'
  curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y --profile minimal
  . "$HOME/.cargo/env" && cd src-tauri && timeout 1200 cargo test --quiet
  ```

  Skip all three when `src-tauri/` is untouched.
- Do not run `pnpm tauri build`, `pnpm tauri dev` or `pnpm dev`. The app needs macOS and a
  desktop, and signing needs CI secrets. Pushing to `test` builds a signed beta; a human checks
  the installed app there.
- `scripts/verify.sh` runs the Rust tests first, so use it only after the install above.
